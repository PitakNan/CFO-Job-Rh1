# CFO-Job-Rh1

**ผังโครงสร้างงาน (Org Chart) กลุ่มงานบริหารการเงินและการคลัง สำนักงานเขตสุขภาพที่ 1**

เว็บเพจหน้าเดียว แตกรายละเอียดภาระงานของกลุ่มงาน CFO จากคำสั่งมอบหมายงานเจ้าหน้าที่ (ร่าง) ฉบับอัปเดต 23 ก.ย. 2569

🔗 https://pitaknan.github.io/CFO-Job-Rh1/

## สิ่งที่แสดง

- **แผนภูมิองค์กรแบบเส้นเชื่อม** — กลุ่มงาน → หัวหน้ากลุ่มงาน → เจ้าหน้าที่ 4 คน → งานหลัก → งานย่อย
- **ก้าน + กิ่งรายการปฏิบัติ** — ใต้กล่องงานย่อยทุกกล่องมีก้านห้อยลงมาแตกกิ่งเป็นรายการปฏิบัติทีละข้อ รวม 81 รายการ
- **ป๊อปอัป Gantt Chart** — คลิกกล่องใดก็ได้เพื่อดูไทม์ไลน์ 12 เดือนตามปีงบประมาณ (ต.ค.–ก.ย. แบ่งไตรมาส 1–4) ระดับรายข้อ พร้อมเส้นบอกเดือนปัจจุบัน
- **แผงรายละเอียด** — ข้อความเต็มของแต่ละหัวข้อตามเอกสารต้นฉบับ

## โครงสร้างข้อมูล

| ระดับ | ตัวอย่าง | จำนวน |
|---|---|---|
| ผู้รับผิดชอบ | พิทักษ์ นันธิ (หัวหน้า) + เจ้าหน้าที่ 4 คน | 5 |
| งานหลัก | นโยบาย/ยุทธศาสตร์, งานจัดการงบประมาณ, บริหารจัดการกองทุน ฯลฯ | 11 |
| งานย่อย (กล่อง) | งาน FDH, กองทุน UC, Planfin, งานสินทรัพย์ (GFMIS) ฯลฯ | 26 |
| รายการปฏิบัติ (กิ่ง) | รายข้อตามเอกสารต้นฉบับ | 81 |

## ไฟล์

- `index.html` — หน้าเว็บทั้งหมดในไฟล์เดียว (ไม่มี dependency ภายนอกนอกจากฟอนต์ Google Fonts)
- `data-tree.json` — ข้อมูลโครงสร้างงาน สำรองไว้แยกต่างหาก

## ข้อควรทราบ

- **เวอร์ชันบน GitHub Pages เป็นแบบอ่านอย่างเดียว** ฟังก์ชันแก้ไขข้อมูลและบันทึกอัตโนมัติทำงานเฉพาะในฉบับ Claude Artifact ซึ่งใช้ระบบฐานข้อมูลและสิทธิ์ของ claude.ai
- **ช่วงเวลาใน Gantt Chart ยังไม่ได้กำหนด** เอกสารคำสั่งมอบหมายงานต้นทางไม่ได้ระบุช่วงเวลาของแต่ละงานไว้ แถบที่ยังไม่กำหนดแสดงเป็นเส้นประเต็มปี ต้องกำหนดเองในฉบับที่แก้ไขได้
- ปีงบประมาณที่ใช้แสดงผลคือ **2570 (ต.ค. 2569 – ก.ย. 2570)**
