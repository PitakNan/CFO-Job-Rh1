# CFO-Job-Rh1

**ผังโครงสร้างงาน (Org Chart) กลุ่มงานบริหารการเงินและการคลัง สำนักงานเขตสุขภาพที่ 1**

เว็บเพจหน้าเดียว แตกรายละเอียดภาระงานของกลุ่มงาน CFO จากคำสั่งมอบหมายงานเจ้าหน้าที่ (ร่าง) ฉบับอัปเดต 23 ก.ย. 2569

🔗 https://pitaknan.github.io/CFO-Job-Rh1/

## สิ่งที่แสดง

- **แผนภูมิองค์กรแบบเส้นเชื่อม** — กลุ่มงาน → หัวหน้ากลุ่มงาน → เจ้าหน้าที่ 4 คน → งานหลัก → งานย่อย
- **ก้าน + กิ่งรายการปฏิบัติ** — ใต้กล่องงานย่อยทุกกล่องมีก้านห้อยลงมาแตกกิ่งเป็นรายการปฏิบัติทีละข้อ รวม 81 รายการ
- **ป๊อปอัป Gantt Chart** — คลิกกล่องใดก็ได้เพื่อดูไทม์ไลน์ 12 เดือนตามปีงบประมาณ (ต.ค.–ก.ย. แบ่งไตรมาส 1–4) ระดับรายข้อ พร้อมเส้นบอกเดือนปัจจุบัน
  - **1 งานมีได้หลายช่วง** เช่น งานตรวจราชการแยกเป็น 2 รอบ (ม.ค.–มี.ค. และ พ.ค.–ก.ค.)
  - แถบลายทาง = ร่างที่ยังไม่ยืนยัน · แถบทึบ = ยืนยันแล้ว · แถบจางใต้ชื่อกล่อง = ช่วงรวมของทั้งกล่อง
- **แผงรายละเอียด** — ข้อความเต็มของแต่ละหัวข้อตามเอกสารต้นฉบับ

## โครงสร้างข้อมูล

| ระดับ | ตัวอย่าง | จำนวน |
|---|---|---|
| ผู้รับผิดชอบ | พิทักษ์ นันธิ (หัวหน้า) + เจ้าหน้าที่ 4 คน | 5 |
| งานหลัก | นโยบาย/ยุทธศาสตร์, งานจัดการงบประมาณ, บริหารจัดการกองทุน ฯลฯ | 11 |
| งานย่อย (กล่อง) | งาน FDH, กองทุน UC, Planfin, งานสินทรัพย์ (GFMIS) ฯลฯ | 26 |
| รายการปฏิบัติ (กิ่ง) | รายข้อตามเอกสารต้นฉบับ | 81 |

## แก้ไขช่วงเวลาได้ผ่านหน้าเว็บ

กดปุ่ม **🔑 เข้าสู่ระบบเพื่อแก้ไขช่วงเวลา** มุมขวาบน แล้วใส่รหัสประจำตัวที่หัวหน้ากลุ่มงานออกให้
จากนั้นลากคลุมเดือนบนแถบ Gantt ได้เลย (ลากด้วยนิ้วบนมือถือได้ด้วย) ระบบบันทึกให้ทันที

| สิทธิ์ | แก้ได้ |
|---|---|
| หัวหน้ากลุ่มงาน | ทุกกล่องงาน |
| เจ้าหน้าที่ | เฉพาะกล่องงานของตัวเอง — แถวของคนอื่นจะจางและลากไม่ได้ |
| ไม่ได้เข้าสู่ระบบ | อ่านอย่างเดียว |

**แก้ได้เฉพาะช่วงเวลา** — โครงสร้างผัง ชื่อกล่อง และข้อความรายการปฏิบัติ แก้ที่ `index.html` แล้ว push เท่านั้น

## ไฟล์

- `index.html` — หน้าเว็บทั้งหมดในไฟล์เดียว (โครงสร้างผังฝังอยู่ใน `DEFAULT_TREE`)
- `data-tree.json` — ข้อมูลโครงสร้างงาน สำรองไว้แยกต่างหาก (ช่วงเวลาในไฟล์นี้คือชุดตั้งต้นที่ใช้ seed เท่านั้น ของจริงอยู่ที่ Worker)
- `worker/` — Cloudflare Worker + Durable Object เก็บช่วงเวลาและตรวจสิทธิ์
  - `src/owners.js` — ตารางว่ากล่องงานไหนเป็นของใคร (สร้างจาก `data-tree.json`)
  - รหัสประจำตัวและกุญแจเซ็น token เก็บเป็น Worker secret (`CFO_CODES`, `CFO_SECRET`) ไม่อยู่ในรีโป

### ถ้าแก้โครงสร้างผัง (เพิ่ม/ลบกล่องงานหรือรายการปฏิบัติ)

ต้องอัปเดตตารางเจ้าของงานใน Worker ด้วย ไม่งั้นกล่องใหม่จะแก้ไม่ได้:

```bash
python -c "import json,io; d=json.load(io.open('data-tree.json',encoding='utf-8')); o={};
def w(n,p):
    p = n['id'] if n.get('kind') in ('person','head') else p
    if 'spans' in n: o[n['id']]=[p,len(n['spans'])]
    [w(c,p) for c in n.get('children',[])]
w(d,None); io.open('worker/src/owners.js','w',encoding='utf-8').write('export const OWNERS = '+json.dumps(o,ensure_ascii=False,indent=1)+';
')"
cd worker && wrangler deploy
```

## ข้อควรทราบ

- **ช่วงเวลาที่แสดงคือของจริงจาก Worker** ไม่ใช่ที่ฝังในไฟล์ — ถ้าเปิดไม่ติด (Worker ล่ม/ออฟไลน์) หน้าเว็บจะถอยไปใช้ชุดที่ฝังไว้ใน `DEFAULT_TREE` และแก้ไขไม่ได้
- ฉบับ Claude Artifact เดิมเลิกเป็นแหล่งข้อมูลจริงแล้ว — **ของจริงคือหน้า GitHub Pages นี้**
- **ช่วงเวลาส่วนใหญ่ยังเป็น "ร่าง"** เอกสารคำสั่งมอบหมายงานต้นทางไม่ได้ระบุช่วงเวลาไว้ จึงร่างจากรอบงานการเงินการคลังที่เป็นมาตรฐาน (งานกำกับติดตาม/รายงานรายเดือน = ทั้งปี, จัดสรรงบและออกคำสั่ง = ต้นปีงบ, ตรวจราชการ = 2 รอบ, Planfin/แผนเงินบำรุง = รอบครึ่งปี) แถบลายทางคือร่างที่รอการยืนยันจากผู้รับผิดชอบ
- ปีงบประมาณที่ใช้แสดงผลคือ **2570 (ต.ค. 2569 – ก.ย. 2570)**
